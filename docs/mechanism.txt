Platform Operation Summary

Biolumos is built as a local-control system for configurable light sessions. The mobile app is used to connect to the device, choose output level, adjust pulse frequency, set timer values, and save reusable presets. The same session settings can then be started again from the app or triggered directly from the device.

At the hardware level, the controller drives four high-power LEDs and supports both continuous and pulsed output. The firmware can operate separate LED groups independently, which allows different timing patterns across the array when that behavior is enabled in the selected preset.

The device also includes a vibration motor that can follow the active light pattern. This gives the user an additional tactile signal without requiring constant attention to the app interface.

Wireless communication is handled through Bluetooth and Wi-Fi. Bluetooth is intended for nearby setup and direct device control, while Wi-Fi can be used for local-network interaction and firmware updates. The product is also designed to remain usable in standalone mode once preferred settings have been stored.

Key interface terms commonly used in project materials include preset, pulse frequency, output level, session timer, channel control, continuous mode, Bluetooth, Wi-Fi, firmware, and OTA update.
