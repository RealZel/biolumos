# Biolumos - Portable Programmable Light Session Platform

Biolumos is a compact near-infrared light device with a mobile companion app for configuring power, pulse patterns, timers, and wireless control. The project focuses on flexible session setup, portability, and straightforward everyday operation.

### Overview

Biolumos uses four high-power 808-810 nm LEDs with configurable output, adjustable pulse frequency from 1 Hz to 10 kHz, and continuous-wave mode. Instead of fixed presets, the platform lets the user shape a session around preferred intensity, timing, and pulsing behavior.

Separate LED groups can be controlled independently, so different parts of the array may run with different pulse settings at the same time. A built-in vibration motor can mirror the active light pattern as an optional tactile cue during a session.

The companion app is used for setup and quick adjustments, while the device itself can also run in standalone mode with one-button start.

### Key Capabilities

- Four high-power LEDs at 808-810 nm
- Adjustable output power from 1% to 100%
- Configurable pulse frequency from 1 Hz to 10 kHz
- Continuous-wave mode
- Independent control for separate LED groups
- Session timer with reusable presets
- Wireless control via Bluetooth and Wi-Fi
- Standalone one-button operation
- Built-in Li-ion battery with at least two full sessions per charge
- OTA firmware update support

### Mounting System

For convenient placement, Biolumos fits into a soft TPU case with a stretchable strap and hook-and-loop fastening. This mounting system helps secure the device on different body areas while keeping the user mobile during a session.

### How the Platform Works

The Biolumos app connects locally to the device over Bluetooth or Wi-Fi. From the app, the user can choose intensity, pulse frequency, channel behavior, and session duration, then start the device immediately or save the setup as a reusable preset.

Inside the device, separate LED groups are driven by the control logic so they can run together or with different timing patterns. This makes the platform useful for users who want finer control than simple on/off or fixed-mode devices typically provide.

The device can also be used without a phone once a preferred routine is set. Firmware updates are delivered over the air to keep the control logic and wireless behavior current.

### Usage Notes

- Do not direct the light into the eyes.
- Start with shorter sessions and lower output if you are new to the device.
- Stop the session if you notice unusual heat, irritation, or discomfort.
- Keep the device dry and inspect the housing and cable before charging.
- Children should use the device only with adult supervision.
